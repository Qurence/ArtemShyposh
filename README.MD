## 📦 Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Qurence/ArtemShyposh.git
   cd ArtemShyposh
   ```
2. **Install dependencies:**
   ```bash
   npm install
   # или
   yarn install
   ```
3. **Run the development server:**
   ```bash
   npm run dev
   # или
   yarn dev
   ```
4. **Build for production:**
   ```bash
   npm run build
   # или
   yarn build
   ```
5. **Preview production build:**
   ```bash
   npm run preview
   # или
   yarn preview
   ```
